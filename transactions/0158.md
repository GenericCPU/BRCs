# BRC-158: Outpoint BEEF

David Case / opl.dev (david.case@shruggr.cloud)

## Abstract

**Outpoint BEEF** is [Atomic BEEF](./0095.md) with a **subject outpoint** instead of a subject transaction id. Encoding, inclusion, and validation follow BRC-95 except as in the table below. The body is a standard [BRC-62](./0062.md) / [BRC-96](./0096.md) BEEF. Use for proofs scoped to a specific output (e.g. 1Sat tip provenance in [BRC-150](../tokens/0150.md)).

## Specification

| | Atomic BEEF ([BRC-95](./0095.md)) | Outpoint BEEF (this BRC) |
|--|----------------------------------|---------------------------|
| Prefix (4 bytes) | `0x01010101` | `0x16a7beef` |
| Subject | TXID (32 bytes) | TXID (32 bytes) + vout (uint32 LE, 4 bytes) |
| Body | BEEF | BEEF (same rules) |
| Graph | Ancestors of the subject **transaction** | Ancestors of the transaction that created the subject **outpoint** |
| Fail if | Subject tx missing, or unrelated txs present | Subject tx missing, or unrelated txs present |

```
16a7beef                                                 // prefix
2222222222222222222222222222222222222222222222222222222222222222 // subject TXID
00000000                                                 // subject vout (uint32 LE)
0200beef                                                 // BEEF V2 (example)
...
```
